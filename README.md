# tabFx
A firefox extension that allows you to search and auto filter similar tabs to the active one in a fast and smart approach.

You can get it from here: 
https://addons.mozilla.org/firefox/addon/tab-fx/

See it on action, here: https://youtu.be/o0TLDZKxJIU

Or check the next articles to find out more about the extension:

[tabFx Guide](https://github.com/2alin/tabFx/wiki/Guide)

[tabFx Changelog](https://github.com/2alin/tabFx/wiki/Changelog)

## Chomium based browsers
Full support is expected in 2025-Q2.

### Experimental access
For users that would like to experiment on Chromium based brwosers, I published (as unlisted) an adapted version of the Firefox one in the Chrome Web Store: https://chromewebstore.google.com/detail/tabfx/dpceadjahgnbmmlhfdiaecpgaadpacab. 
Feel free to install it although I can't guarantee the same support as in Firefox for the time being.
